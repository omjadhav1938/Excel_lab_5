# Excel Lab 5 – Conditional Formatting and Visual Analytics

## 📌 Overview

This lab focuses on using **Conditional Formatting in Excel** to identify important business patterns and insights from the DMart sales dataset.

## 🎯 Tasks Completed

* Highlighted **high discount values** using Color Scales
* Identified **top-performing products** using Top 10 Rules
* Converted raw numerical data into visual insights
* Improved business data interpretation

## 🛠️ Skills Used

* Microsoft Excel
* Conditional Formatting
* Color Scales
* Top/Bottom Rules
* Data Visualization
* Business Analytics
